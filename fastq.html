🧬 Arquivos FASTQ

FASTQ

Um arquivo FASTQ é um formato de texto utilizado para armazenar sequências biológicas obtidas por sequenciamento (como em NGS), junto com as pontuações de qualidade associadas a cada base. É o formato padrão para dados brutos de sequenciamento.

Cada entrada ocupa quatro linhas:
1. Identificador (header): linha inicia com "@" seguido por um ID único da leitura.
2. Sequência de nucleotídeos: contém as bases (A, T, C, G e N para bases incertas).
3. Separador: linha começa com "+".
4. Linha de valores de qualidade Phred (em código ASCII).

Código ASCII

O FASTQ não grava números diretamente (como o Phred Score 30 ou 40), mas sim caracteres ASCII que representam esses valores. Isso economiza espaço e facilita a leitura por programas.

📚 Referências deste módulo

COCK, P. J. A. et al. The Sanger FASTQ file format for sequences with quality scores, and the Solexa/Illumina FASTQ variants. Nucleic Acids Research, 2010. Disponível em: <https://doi.org/10.1093/nar/gkp1137>.
Drive5 — Quality scores in FASTQ files. Disponível em: <https://www.drive5.com>.

🎯 Atividade 3 — Download dos Dados

Objetivo: Baixar os dados necessários para o projeto.

1 — Acesse o banco de dados, encontre o código SRA e execute:

/CAMINHO/PARA/O/EXECUTÁVEL/prefetch SRRXXXXXX SRRYYYYYY SRRZZZZZZ

2 — Converta os dados .SRA para FASTQ (paired-end):

/CAMINHO/PARA/O/EXECUTÁVEL/fastq-dump --split-files --progress --outdir /CAMINHO/DE/SAIDA/
# Para single-end: remova --split-files
