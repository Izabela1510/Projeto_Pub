🧬 Arquivos FASTQ

FASTQ

Um arquivo FASTQ é um formato de texto utilizado para armazenar sequências biológicas obtidas por sequenciamento (como em NGS), junto com as pontuações de qualidade associadas a cada base. É o formato padrão para dados brutos de sequenciamento.

Cada entrada ocupa quatro linhas:
1. Identificador (header): linha inicia com "@" seguido por um ID único da leitura.
2. Sequência de nucleotídeos: contém a sequência de bases (A, T, C, G e N para bases incertas).
3. Separador: linha começa com "+", usada apenas para separar a sequência da linha de qualidade.
4. Linha de valores de qualidade: contém a pontuação de qualidade Phred (em código ASCII) atribuída a cada base da sequência correspondente. Quanto maior a pontuação, maior é a confiança na identificação daquela base.

Código ASCII

O FASTQ não grava números diretamente (como o Phred Score 30 ou 40), mas sim caracteres ASCII que representam esses valores. Isso economiza espaço e facilita a leitura por programas. Cada caractere ASCII tem um valor numérico associado.
