O que é ambiente conda?

  • Um ambiente Conda é um espaço isolado dentro do gerenciador de pacotes Conda (usado no Anaconda ou Miniconda) que permite instalar e gerenciar versões específicas de pacotes, bibliotecas e dependências sem interferir em outros projetos.
  • Uma boa prática é utilizar um ambiente conda para cada etapa no processamento dos dados.

Como usar?

1. Instalar Conda

  • Baixar e instalar Anaconda (completo) ou Miniconda (mais leve).
  • Verificar instalação: 
    conda --version

2. Criar um ambiente

  • Criar ambiente com nome específico e versão do Python desejada: 
    conda create -n meu_ambiente python=3.11

3. Ativar e desativar ambiente

  • Ativar ambiente: 
    conda activate meu_ambiente

  • Desativar ambiente: 
    conda deactivate

4. Instalar pacotes

⚠️ Pesquise no Google o nome da ferramenta seguido de conda install. Certifique-se de instalar apenas com o ambiente ativo!

  • Instalar pacotes: 
    conda install numpy pandas

  • Instalar de canais específicos: 
    conda install -c conda-forge pacote

Objetivo: Marcar duplicatas e recalibrar qualidade de bases.

1 - Picard MarkDuplicates:

#!/bin/bash
INPUT_DIR="/caminho/para/seus/bams"
OUTPUT_DIR="/caminho/para/salvar/resultados"
PICARD_JAR="/caminho/para/seu/picard.jar"
MEMORY="30g"

for i in "$INPUT_DIR"/*.bam; do
    base=$(basename "$i")
    prefix="${base%%.bam}"
    out="${OUTPUT_DIR}/${prefix}.rmdup.bam"
    met="${OUTPUT_DIR}/${prefix}.metrics"
    java -Xmx"$MEMORY" -jar "$PICARD_JAR" MarkDuplicates METRICS_FILE="$met" I="$i" O="$out"
done

💡 Importante! Configure os caminhos no topo do script.


2 - GATK BaseRecalibrator + ApplyBQSR:

#!/bin/bash
DIR_DUPLICATAS='/CAMINHO/ARQUIVOS/BAM/'
DIR_OUTPUT='/CAMINHO/SAIDA/'
REFHG38='/CAMINHO/hg38.fa'
KNOWIND='/CAMINHO/known_indels.vcf.gz'
KNOWSNP='/CAMINHO/dbsnp138.vcf.gz'
KNOWMIND='/CAMINHO/Mills_1000G.vcf.gz'

mkdir -p ${DIR_OUTPUT}
cd ${DIR_DUPLICATAS}

for i in $(ls -1 *.rmdup.bam | sed 's/.rmdup.bam//'); do
  gatk --java-options "-Xmx60G -XX:ParallelGCThreads=24" BaseRecalibrator \
    -I ${i}.rmdup.bam -R ${REFHG38} \
    --known-sites ${KNOWIND} --known-sites ${KNOWSNP} --known-sites ${KNOWMIND} \
    -O ${DIR_OUTPUT}/${i}.recal_data.table
done

for i in $(ls -1 *.rmdup.bam | sed 's/.rmdup.bam//'); do
  gatk --java-options "-Xmx60G -XX:ParallelGCThreads=24" ApplyBQSR \
    -R ${REFHG38} -I ${i}.rmdup.bam \
    --bqsr-recal-file ${DIR_OUTPUT}${i}.recal_data.table \
    -O ${DIR_OUTPUT}/${i}.recal.bam
done

Objetivo: Detecção e genotipagem de variantes genéticas (SNPs e indels).

1 - GATK HaplotypeCaller:

REFERENCE_GENOME="/caminho/genoma_referencia.fasta"
INPUT_BAM_DIR="/caminho/bams_recalibrados"
OUTPUT_DIR="/caminho/resultados_finais"
MEMORY="100g"

VARCALL_DIR="${OUTPUT_DIR}/1_variant_calling_gvcfs"
FILTERED_DIR="${OUTPUT_DIR}/2_vcf_filtered"
FINAL_DIR="${OUTPUT_DIR}/3_vcf_final"
mkdir -p "$VARCALL_DIR" "$FILTERED_DIR" "$FINAL_DIR"

# Passo 1: HaplotypeCaller
for input_bam in "$INPUT_BAM_DIR"/*.recal.bam; do
    prefix=$(basename "${input_bam}" .recal.bam)
    gatk --java-options "-Xmx${MEMORY}" HaplotypeCaller \
        -R "$REFERENCE_GENOME" -I "$input_bam" \
        -O "${VARCALL_DIR}/${prefix}.g.vcf.gz" -ERC GVCF
done

# Passo 2: GenotypeGVCFs
gatk --java-options "-Xmx${MEMORY}" GenotypeGVCFs \
    -R "$REFERENCE_GENOME" "${VARCALL_DIR}/*.g.vcf.gz" \
    -O "${FILTERED_DIR}/cohort_genotyped.vcf.gz"

# Passo 3: VariantFiltration
gatk --java-options "-Xmx${MEMORY}" VariantFiltration \
    -R "$REFERENCE_GENOME" -V "${FILTERED_DIR}/cohort_genotyped.vcf.gz" \
    -O "${FILTERED_DIR}/cohort_genotyped_filtered.vcf.gz" \
    --filter-expression "QD < 2.0" --filter-name "QD2" \
    --filter-expression "FS > 60.0" --filter-name "FS60" \
    --filter-expression "MQ < 40.0" --filter-name "MQ40"

# Passo 4: SelectVariants (apenas PASS)
gatk --java-options "-Xmx${MEMORY}" SelectVariants \
    -R "$REFERENCE_GENOME" -V "${FILTERED_DIR}/cohort_genotyped_filtered.vcf.gz" \
    -O "${FINAL_DIR}/cohort_final_PASS.vcf.gz" --exclude-filtered

3 - Converter VCF → MAF (para maftools):

FASTA='/CAMINHO/GENOMA.fasta'
VEP_PATH='/CAMINHO/VEP/bin/'
VEP_DATA='/CAMINHO/VEP/cache/'
DIR_ENTRADA_VCF='/CAMINHO/VCFs/'
DIR_SAIDA_MAF='/CAMINHO/MAF/'
mkdir -p ${DIR_SAIDA_MAF}

for i in *_annotated_final.vcf; do
    SAMPLE_NAME=$(basename "$i" | cut -d'.' -f1)
    vcf2maf.pl --input-vcf $i \
        --output-maf ${DIR_SAIDA_MAF}/${SAMPLE_NAME}.maf \
        --ncbi-build GRCh38 --ref-fasta ${FASTA} \
        --vep-path ${VEP_PATH} --vep-data ${VEP_DATA} \
        --tumor-id ${SAMPLE_NAME} --vcf-tumor-id ${SAMPLE_NAME}
done
