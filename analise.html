📊 Análises

Linguagem R

R é uma linguagem de programação livre amplamente utilizada para computação estatística e visualização de dados. Permite:

  • Processamento de dados: importar, limpar e transformar grandes conjuntos de dados.
  • Análise estatística: desde testes simples até modelagens complexas.
  • Visualização: gráficos de alta qualidade para comunicar resultados.

R na Bioinformática

Amplamente aplicado para processar dados de sequenciamento, conduzir análises de expressão diferencial, interpretar variantes genéticas e realizar análises estatísticas em grandes conjuntos de dados biológicos.

RStudio

IDE criado para facilitar o uso do R, com editor de código, console, painel de ambiente e painéis auxiliares para gráficos e relatórios.

Pacotes úteis na bioinformática

  • dplyr: manipulação e transformação de dados.
  • ggplot2: criação de gráficos sofisticados.
  • vcfR: leitura e visualização de arquivos VCF.
  • maftools: análise e visualização de variantes somáticas em dados de exoma/genoma.

R — R CORE TEAM. R: A language and environment for statistical computing. Vienna: R Foundation for Statistical Computing, 2023.

🎯 Atividade 10 — Análises

Objetivo: Realizar análises com os dados processados usando o software R.

⚠️ Utilize o software R para esta atividade!

# Instalação (executar apenas uma vez):
# if (!require("BiocManager", quietly = TRUE)) install.packages("BiocManager")
# BiocManager::install("maftools")

library(maftools)

laml.maf  = system.file('extdata', 'tcga_laml.maf.gz', package = 'maftools')
laml.clin = system.file('extdata', 'tcga_laml_annot.tsv', package = 'maftools')

laml = read.maf(maf = laml.maf, clinicalData = laml.clin, verbose = FALSE)

# Por padrão plota os 20 genes mais mutados
oncoplot(maf = laml, draw_titv = TRUE)
