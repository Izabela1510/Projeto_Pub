🔎 Chamada de Variantes

Definição

Chamada de variantes é o processo de identificar alterações genéticas (SNPs, inserções e deleções) em relação a um genoma de referência. Fundamental para detectar mutações e compreender doenças genéticas.

HaplotypeCaller GATK

Identifica variantes genéticas (SNPs e indels) comparando os dados de sequenciamento com o genoma de referência. A saída é um arquivo VCF (Variant Call Format).

Colunas essenciais do VCF:
  • CHROM: cromossomo onde a variante está localizada.
  • POS: posição inicial da variante.
  • REF: alelo de referência na posição.
  • ALT: alelo(s) alternativo(s) observado(s).
  • QUAL: score de qualidade Phred.
  • FILTER: indica se a variante passou pelos filtros.
  • INFO: informações adicionais e métricas de qualidade.
Genótipos:
  • 0/0: homozigoto referência
  • 0/1: heterozigoto
  • 1/1: homozigoto alternativo
  • ./. genótipo não chamado

🎯 Atividade 8 — Chamada de Variantes

Objetivo: Detectar variantes genéticas (SNPs e indels) a partir dos arquivos BAM.

REFERENCE_GENOME="/caminho/genoma_referencia.fasta"
INPUT_BAM_DIR="/caminho/bams_recalibrados"
OUTPUT_DIR="/caminho/resultados"
MEMORY="100g"

VARCALL_DIR="${OUTPUT_DIR}/1_gvcfs"
FILTERED_DIR="${OUTPUT_DIR}/2_filtered"
FINAL_DIR="${OUTPUT_DIR}/3_final"
mkdir -p "$VARCALL_DIR" "$FILTERED_DIR" "$FINAL_DIR"

# Passo 1: HaplotypeCaller
for input_bam in "$INPUT_BAM_DIR"/*.recal.bam; do
    prefix=$(basename "${input_bam}" .recal.bam)
    gatk --java-options "-Xmx${MEMORY}" HaplotypeCaller \
        -R "$REFERENCE_GENOME" -I "$input_bam" \
        -O "${VARCALL_DIR}/${prefix}.g.vcf.gz" -ERC GVCF
done

# Passo 2: GenotypeGVCFs
gatk --java-options "-Xmx${MEMORY}" GenotypeGVCFs \
    -R "$REFERENCE_GENOME" "${VARCALL_DIR}/*.g.vcf.gz" \
    -O "${FILTERED_DIR}/cohort_genotyped.vcf.gz"

# Passo 3: VariantFiltration
gatk --java-options "-Xmx${MEMORY}" VariantFiltration \
    -R "$REFERENCE_GENOME" -V "${FILTERED_DIR}/cohort_genotyped.vcf.gz" \
    -O "${FILTERED_DIR}/cohort_filtered.vcf.gz" \
    --filter-expression "QD < 2.0" --filter-name "QD2" \
    --filter-expression "FS > 60.0" --filter-name "FS60" \
    --filter-expression "MQ < 40.0" --filter-name "MQ40"

# Passo 4: SelectVariants (apenas PASS)
gatk --java-options "-Xmx${MEMORY}" SelectVariants \
    -R "$REFERENCE_GENOME" -V "${FILTERED_DIR}/cohort_filtered.vcf.gz" \
    -O "${FINAL_DIR}/cohort_final_PASS.vcf.gz" --exclude-filtered

💡 Configure os caminhos no topo do script antes de executar.
