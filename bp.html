✅ Boas Práticas GATK

Definição

As boas práticas do GATK são recomendações e fluxos de trabalho padronizados desenvolvidos pelo Broad Institute para garantir resultados reprodutíveis, precisos e de alta qualidade na análise de dados genômicos NGS.

Etapas realizadas antes da chamada de variantes:

  • Marcação de duplicatas: detecta leituras duplicadas por PCR e as marca no arquivo BAM (ex.: MarkDuplicates do Picard).
  • Correção de base (BQSR): ajusta as pontuações de qualidade das bases com BaseRecalibrator e ApplyBQSR, comparando com bancos de variantes conhecidos (dbSNP, 1000 Genomes).

📚 Referências deste módulo

GATK — MCKENNA, A. et al. The Genome Analysis Toolkit: a MapReduce framework for analyzing next-generation DNA sequencing data. Genome Research, 2010.
PICARD — BROAD INSTITUTE. Picard Toolkit. Broad Institute, 2019.

🎯 Atividade 7 — Boas Práticas GATK

Objetivo: Marcar duplicatas e recalibrar qualidade de bases.

1 — Marcar duplicatas com Picard:

#!/bin/bash
INPUT_DIR="/caminho/para/seus/bams"
OUTPUT_DIR="/caminho/para/salvar/resultados"
PICARD_JAR="/caminho/para/seu/picard.jar"
MEMORY="30g"

for i in "$INPUT_DIR"/*.bam; do
    base=$(basename "$i")
    prefix="${base%%.bam}"
    out="${OUTPUT_DIR}/${prefix}.rmdup.bam"
    met="${OUTPUT_DIR}/${prefix}.metrics"
    java -Xmx"$MEMORY" -jar "$PICARD_JAR" MarkDuplicates METRICS_FILE="$met" I="$i" O="$out"
done

2 — Recalibrar bases com GATK BaseRecalibrator + ApplyBQSR:

DIR_DUPLICATAS='/CAMINHO/ARQUIVOS/BAM/'
DIR_OUTPUT='/CAMINHO/SAIDA/'
REFHG38='/CAMINHO/hg38.fa'
KNOWIND='/CAMINHO/known_indels.vcf.gz'
KNOWSNP='/CAMINHO/dbsnp138.vcf.gz'
KNOWMIND='/CAMINHO/Mills_1000G.vcf.gz'

for i in $(ls -1 *.rmdup.bam | sed 's/.rmdup.bam//'); do
  gatk --java-options "-Xmx60G" BaseRecalibrator \
    -I ${i}.rmdup.bam -R ${REFHG38} \
    --known-sites ${KNOWIND} --known-sites ${KNOWSNP} --known-sites ${KNOWMIND} \
    -O ${DIR_OUTPUT}/${i}.recal_data.table
  gatk --java-options "-Xmx60G" ApplyBQSR \
    -R ${REFHG38} -I ${i}.rmdup.bam \
    --bqsr-recal-file ${DIR_OUTPUT}${i}.recal_data.table \
    -O ${DIR_OUTPUT}/${i}.recal.bam
done
